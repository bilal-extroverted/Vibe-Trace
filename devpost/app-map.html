Architecture & App Map

VibeTrace System Map

A developer-first observability harness and agent communication protocol that eliminates blind faith in AI code generation through real-time diffs, mechanical integrity checks, and persistent SQLite tracking.

End-to-End Agent Execution Flow

1

Agent Skill Discovery & Initialization

Coding agent loads skills/vibetrace/SKILL.md and confirms the VibeTrace telemetry daemon is listening on http://localhost:3000.

2

Task Start & vibetrace.md Synchronization

Agent writes vibetrace.md with status: in_progress, user task intent, and step checklist. VibeTrace SSE broadcasts live status to the UI top bar and right pane.

3

Live Debounced File Watching

server/watcher.js monitors filesystem mutations with a 1500ms sliding debounce window and diff hash deduplication, stabilizing active file writes.

4

Mechanical AI Harness Engineering Audit

Upon completion or stabilization, server/harness/harnessEngine.js executes real mechanical checks: syntax compilation via Node, protected files guard (.env, keys), secret scanning, and dependency boundaries.

5

Causal Intelligence & SQLite Persistence

Diffs and metadata are analyzed via OpenRouter (or heuristic fallback) and permanently stored in vibetrace.db via Node.js native node:sqlite.

6

Developer Observability & Interactive Q&A

Developer inspects the 3-pane light-theme dashboard, examines line-by-line diffs with line numbers, and asks technical questions via the interactive AI query engine.

⚡ Protocol & Skill Layer

Defines how any autonomous coding agent communicates its state, intent, and progress.

  • skills/vibetrace/SKILL.md: Agent instructions and workflow specification
  • vibetrace.md: Live YAML frontmatter protocol in workspace root
  • server/harness/protocol.js: Parser and serializer for protocol synchronization

🛡️ Mechanical Harness Engine

Automated software engineering verification guards that run without human intervention.

  • Syntax Integrity: node --check AST compilation verification
  • Protected Files Guard: Blocks modifications to credentials, dotfiles, and keys
  • Secret Scanner: Scans diff content for leaked tokens and private keys
  • Dependency Guard: Verifies package boundaries and structural imports

💾 Persistent Storage

Zero-configuration native SQLite database engine storing complete telemetry history.

  • server/db.js: Implemented with Node.js LTS native node:sqlite
  • vibetrace.db: Normalized schema: projects, traces, diffs, queries
  • Session Resilience: Retains full trace history across server restarts

🖥️ 3-Pane Light Theme Dashboard

Clean developer interface optimized for readability, side-by-side IDE use, and diff inspection.

  • Left Pane: Project metadata card, search bar, and historical traces feed
  • Middle Pane: Commit tags, file tabs, and syntax-highlighted code diffs
  • Right Pane: Live vibetrace.md guidance, harness audit, AI Q&A box, and plain-English summary

📁 Codebase Manifest

File / Directory Component Responsibility

skills/vibetrace/SKILL.md Agent instruction skill file guiding agents on running the harness and reporting.

server/watcher.js Chokidar watcher with sliding debouncing (1500ms), diff deduplication, and completion trigger.
server/db.js Persistent SQLite database layer using Node.js built-in node:sqlite.
server/harness/harnessEngine.js Mechanical software engineering checks: syntax, protected files, secrets, dependencies.
server/harness/protocol.js Robust YAML frontmatter and markdown parser/writer for vibetrace.md.
server/gitService.js Multi-mode Git inspection (working tree, index, untracked, recent commit fallback).

public/app.js Frontend controller handling SSE streams, diff rendering, theme toggling, and AI Q&A.
public/diffViewer.js Syntax-highlighted diff engine with line numbers, file filtering, and chunk headers.
